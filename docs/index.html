视频提取 · video-saver

粘贴链接，提取无水印内容

一个本地运行的视频 / 图文提取下载站：粘贴分享链接 → 解析 → 预览 → 一键下载无水印视频，图文自动打包为 ZIP。

Flask yt-dlp 纯前端无依赖

特性

  • 抖音专用解析器：任意链接规整为作品 ID，提取无水印直链；解析失败自动降级 yt-dlp
  • 多平台支持：B站、快手、微博、小红书、西瓜视频、YouTube、TikTok 等由 yt-dlp 通用引擎处理
  • 图文打包：图文作品逐张下载后自动打包 ZIP
  • 可选 Cookie：遇到反爬限制时，上传 cookies.txt（Netscape 格式）即可，仅存于服务内存
  • 毛玻璃界面：中文、无第三方 CDN、无 Node 依赖

快速开始

克隆仓库后在本机运行（示例环境：Python 3.12）：

pip install -r requirements.txt
python app.py

浏览器打开 http://127.0.0.1:5000，粘贴分享链接（整段分享文案也可以）即可解析下载。
